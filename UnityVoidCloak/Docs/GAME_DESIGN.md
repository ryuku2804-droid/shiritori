## 2. 世界

- **鐘の王国 カリヨン**：中世の城塞都市。王城の鐘楼に大鐘〈暁鐘（ぎょうしょう）〉が吊られている。
- 暁鐘の音は、光と音を食べる闇〈静寂（しじま）〉を押し返していた。
- ある夜、暁鐘が砕けて、しじまが王国を飲み込んだ。飲まれた人々は、死ぬ直前の一瞬を永遠に繰り返す〈残響〉になった。

## 3. 登場人物

- **アルドレン**（主人公）：鐘守りの騎士団の一人。しじまを見て目と顔を奪われた。フードの中は黒いVoid。体に残った「暁鐘の最後の響き」で、歩くたびに波を出して世界を知る。
- **リーネ**：アルドレンの妹。暗闇の中で彼を導く声。正体は、しじまの中心に取り込まれた彼女の声（後半で判明）。
- **沈黙の騎士たち**：しじまに飲まれた鐘守り。各章の最後のボス。
  - 第一章 **ガレス**：アルドレンの仲間。鐘を砕きに行くアルドレンを止めようとして斬られた。
  - 第二章 **オルヴァン**：修道院の鐘守り。鐘が声を食べることを知りながら黙っていた。
  - 第三章 **アルドレンの残響**：あの夜のアルドレン自身。

## 4. 本当の話（章ごとに少しずつ明かす）

| 章 | 明かされること | どこで |
|---|---|---|
| 序章 | 今年の捧げものはリーネ。儀式の夜、剣を持った騎士が現れて鐘楼へ向かった（誰かはまだわからない） | 礼拝堂の司祭の残響、大広間の残響劇 |
| 第一章 | **鐘を砕いたのはアルドレン**。仲間のガレスを斬ってまで | 商人の残響、ガレスの残響劇 |
| 第二章 | **暁鐘は子どもの声を食べて鳴る**。鐘守りたちは百年それを黙っていた | 残響劇「選ばれた子どもたち」、オルヴァンの残響劇 |
| 第三章 | 砕けた鐘からあふれたしじまがリーネの声を呑み、**アルドレンは声を返してもらう代わりに目をしじまに差し出した**（だから盲目）。リーネの声は**しじまの心臓**になって、塔の上にある | アルドレンの残響の残響劇、塔の頂上のリーネ |

- 暁鐘は、毎年一人の子どもの「声」を捧げることで鳴り続けていた。捧げられた子は二度と話せない。
- その年に選ばれたのはリーネだった。
- 妹を守るために暁鐘を砕いたのはアルドレン自身。その結果、しじまが溢れ出した。
- 捧げかけられていたリーネの声は、しじまの心臓になった。暗闇で兄を導く「リーネの声」は、その心臓から届いていた。

## 5. エンディング（第三章の塔の頂上で選ぶ、**制作済み**）

1. **暁の鐘**（鐘を鋳直す）：光が戻る。でも次の年、また一人の子の声が捧げられる。
2. **静寂の兄妹**（しじまとともに眠る）：鐘を鳴らさず、光は戻らない。兄妹は闇の中で寄り添って眠る。
3. **残響の騎士**（真エンド：最後の響きを鐘に渡す）：アルドレンは光の粒になってほどけ、鐘は誰の声も食べずに鳴り、リーネは声を取り戻す。
   - **記憶のかけら**を3つ全部集めたときだけ選べる。かけらは各章（序章・第一章・第二章）の**空洞の壁の奥の隠し部屋**の残響にある。
   - 集めていないと「？？？（記憶のかけら　n / 3）」と出て選べない。

## 6. ゲームの仕組み

### 波（エコー）
| 行動 | 波の大きさ | リスク |
|---|---|---|
| 歩く | 小（半径11、約3秒に1回） | 低い |
| 走る | 中（半径22、約1.6秒に1回） | 敵に聞かれやすい |
| 鐘打ち（剣で地面を打つ） | 大（半径50）、8秒待てば再使用可 | 周りの敵が一斉に気づく |
| 立ち止まる | なし | 何も見えないが、見つからない |

- 波が通ったものは一瞬光り、約1秒で完全に消える。
- 見えるのはプレイヤー自身だけ。
- 色：地形＝白、敵＝赤、アイテム・残響＝金。
- 敵が立てる音（足音・鎧の音）は聞こえるだけで、波は出ない。

### 高難度の戦い（エコーで戦う）
- 敵の攻撃は**音の輪**（ゆっくり広がる赤い輪）。触れると死ぬ。届く瞬間にパリィで跳ね返す（敵にダメージ＋動けなくする）。柱・壁の陰なら届かない。
- 敵は見えない。足音（3D）で位置を聞き、自分の波で一瞬だけ確かめる。斬る音で別の敵が寄ってくる。
- **石を投げる**：落ちた所で波が出て、その場所が見え、聴き手がそこへ向かう。
- **一撃で死ぬ**。祠からやり直し、敵は全員元に戻る。
- **ボス：沈黙の騎士**（各章の最後）。前からの攻撃は弾く。輪を跳ね返して動けなくするか、背中を取る。弱ると「静寂の帳」で騎士の足音の波を消す。
- 第一章のボス：**ガレス**（アルドレンのかつての仲間）。倒すと残響劇で「鐘を砕いたのはアルドレン」と明かされる。

### 戦闘
- 弱攻撃（左クリック / X）・強攻撃（E / RB）・パリィ（Q / LB）。
- 聴き手は息を吸う音のあと叫び、叫びが赤い輪になって広がる。輪が届く瞬間にパリィすると跳ね返る。
- 剣のパリィに成功すると敵は1.8秒動けず、その間のダメージは2倍。跳ね返した輪は必ず当たり、敵を2.2秒動けなくしてから2ダメージ（硬直の倍率込みで、聴き手には4、沈黙の騎士には3）。
- 騎士は一撃で倒れる。聴き手の体力は3、抜け殻の鎧は6、沈黙の騎士ガレスは9。
- 剣を振ると音が出るので、波が出る（周りが見えるが、敵にも聞こえる）。
- パリィ成功時は鐘のような大きな波が出る。

### 音の謎解き
- **歌う扉**：近づくと、まわりの鐘が順番に鳴る（音はそれぞれの鐘の場所から聞こえる）。同じ順番で鐘を鳴らすと開く。間違えると最初から。鐘の音は大きいので聴き手が寄ってくる。
- **空洞の壁**：見た目は普通の壁。鐘打ちなど大きな波が届くと低く響いて金色に光る。強攻撃で壊すと隠し部屋がある。
- 序章の隠し部屋には、幼いリーネの残響「兄さん、鐘の音って、どうしてこんなに悲しいの？」（声を捧げる儀式への伏線）。

### 死亡とセーブ
- 各地の小さな鐘の祠で鐘を鳴らす（F / A）とセーブされ、死ぬとそこから再開する。
- 鐘を鳴らすと体力が全回復し、金色の大きな波が広がる。
- 聴き手は鐘の音を嫌い、聞くと逃げていく（暁鐘の音がしじまを押し返していたことの名残）。祠のまわりは安全な場所になる。

### 成長（未定・後から追加できる形で作る）
- 「波の範囲」「波の持続時間」「足音の静かさ」「鐘打ちの待ち時間」などを、**数値の表（ScriptableObject）でまとめて管理**する。
- 成長方法（鐘の欠片だけにするか、スキルを選ぶか）は、後から決めて数値を変えるだけで追加できるようにする。

## 9. 画面と音

- 画面表示はほぼ無し。HPはマントの欠け具合と画面の端の暗さで示す。
- タイトル画面：暗闇に立つ騎士。数秒ごとの波で、まわりの廃墟と暁鐘の破片が一瞬見える。はじめから / つづきから / おわる。
- 章のはじめに章タイトル、章の終わりに締めの文字。暗転して次の章へ。
- 一時停止（Esc / Start）：つづける / タイトルへもどる。
- セーブは自動：章に入ったとき・祠を鳴らしたとき。（**制作済み**）
- 音が中心。立体音響で敵の位置がわかる。ヘッドホン推奨。
- 効果音はすべてプログラムで合成（足音、鐘打ち、剣、斬撃、パリィ、被弾、祠の鐘、聴き手の足音・叫び・断末魔、鎧のきしみ・剣を振り上げる音・崩れる音、暗闇の風）。石の回廊の残響をかける。
- 足音は毎歩聞こえるが、見える波は間隔をあけて出る（聞こえる＝見える、ではない）。
- 会話はリーネだけボイス、ほかは文字。ムービーなし。日本語のみ。
- 操作はキーボード・マウス＋ゲームパッド。
