## 2. 世界

- **鐘の王国 カリヨン**：中世の城塞都市。王城の鐘楼に大鐘〈暁鐘（ぎょうしょう）〉が吊られている。
- 暁鐘の音は、光と音を食べる闇〈静寂（しじま）〉を押し返していた。
- ある夜、暁鐘が砕けて、しじまが王国を飲み込んだ。飲まれた人々は、死ぬ直前の一瞬を永遠に繰り返す〈残響〉になった。

## 3. 登場人物

- **アルドレン**（主人公）：鐘守りの騎士団の一人。しじまを見て目と顔を奪われた。フードの中は黒いVoid。体に残った「暁鐘の最後の響き」で、歩くたびに波を出して世界を知る。
- **リーネ**：アルドレンの妹。暗闇の中で彼を導く声。正体は、しじまの中心に取り込まれた彼女の声（後半で判明）。
- **沈黙の騎士たち**：しじまに飲まれた鐘守りの仲間。各章のボスで、鐘の欠片を持つ。

## 4. 本当の話（後半で明かす）

- 暁鐘は、毎年一人の子どもの「声」を捧げることで鳴り続けていた。捧げられた子は二度と話せない。
- その年に選ばれたのはリーネだった。
- 妹を守るために暁鐘を砕いたのはアルドレン自身。その結果、しじまが溢れ出した。
- 捧げかけられていたリーネの声は、しじまの心臓になった。

## 5. エンディング

1. **鐘を鋳直す**：光が戻るが、再びリーネの声が捧げられる。
2. **しじまを受け入れる**：鐘を鳴らさず、闇とともに眠る。残響たちは消えていく。
3. **真エンド**：自分の中の「最後の響き」を鐘に渡す。アルドレンはParticleになってほどけ、鐘の音が戻り、リーネは声を取り戻す。

## 6. ゲームの仕組み

### 波（エコー）
| 行動 | 波の大きさ | リスク |
|---|---|---|
| 歩く | 小（半径 約8m、約1.8秒に1回） | 低い |
| 走る | 中（約15m、約0.9秒に1回） | 敵に聞かれやすい |
| 鐘打ち（剣で地面を打つ） | 大（約30m）、一定時間待てば再使用可 | 周りの敵が一斉に気づく |
| 立ち止まる | なし | 何も見えないが、見つからない |

- 波が通ったものは一瞬光り、1〜2秒で完全に消える。
- 見えるのはプレイヤー自身だけ。
- 色：地形＝白、敵＝赤、アイテム・残響＝金。
- 敵が立てる音（足音・鎧の音）も、小さな赤い波として見える。頻度は、徘徊中は約3.5秒、追跡中は約1.1秒に1回。

### 戦闘
- 弱攻撃（左クリック / X）・強攻撃（E / RB）・パリィ（Q / LB）。
- 聴き手は攻撃の前に叫ぶ（赤い波）。それが合図で、パリィの目安。
- パリィに成功すると敵は1.8秒動けず、その間のダメージは2倍。
- 騎士の体力は5、聴き手は4。
- 剣を振ると音が出るので、波が出る（周りが見えるが、敵にも聞こえる）。
- パリィ成功時は鐘のような大きな波が出る。

### 死亡とセーブ
- 各地の小さな鐘の祠で鐘を鳴らす（F / A）とセーブされ、死ぬとそこから再開する。
- 鐘を鳴らすと体力が全回復し、金色の大きな波が広がる。
- 聴き手は鐘の音を嫌い、聞くと逃げていく（暁鐘の音がしじまを押し返していたことの名残）。祠のまわりは安全な場所になる。

### 成長（未定・後から追加できる形で作る）
- 「波の範囲」「波の持続時間」「足音の静かさ」「鐘打ちの待ち時間」などを、**数値の表（ScriptableObject）でまとめて管理**する。
- 成長方法（鐘の欠片だけにするか、スキルを選ぶか）は、後から決めて数値を変えるだけで追加できるようにする。

## 7. ステージ

| 章 | 場所 | 内容 |
|---|---|---|
| 序章 | 崩れた鐘楼 | 波・攻撃・パリィのチュートリアル |
| 1 | 灰の城下町 | 石畳、井戸、市場の残響 |
| 2 | 沈んだ修道院 | 地下墓所。聴き手の巣 |
| 3 | 霧の森と巡礼路 | 開けた場所。囁きが偽の道を作る |
| 4 | 王城 | 声を捧げる儀式の真実が明かされる |
| 5 | 鐘のない塔 | しじまの中心。リーネとの対峙 |

### 建物の作り方（部品キット方式）
- すべて数式でParticle化する。ただし建物1つずつを数式で作ると量が多すぎるので、**中世建築の部品を数式で作り、組み合わせる**。
  - 部品の例：石壁（積み石の目地つき）、アーチ、柱、窓、扉、階段、円塔、尖り屋根、城壁の凸凹（狭間）、樽、木箱、井戸、墓石
- 部品はInspectorで寸法を変えられ、Unityのシーンに並べて組み立てる。

## 8. 敵

| 名前 | 特徴 |
|---|---|
| 聴き手 | 耳だけが大きい盲目の修道士。音だけで追ってくる。基本の敵 |
| 抜け殻の鎧 | 中身のない騎士の鎧。静かに徘徊し、波の中でしか見えない |
| 囁き | 偽の波で、存在しない壁や道を見せる |
| 沈黙の騎士（ボス） | かつての仲間。各章に1体、鐘の欠片を持つ |

## 9. 画面と音

- 画面表示はほぼ無し。HPはマントの欠け具合と画面の端の暗さで示す。
- 音が中心。立体音響で敵の位置がわかる。ヘッドホン推奨。
- 効果音はすべてプログラムで合成（足音、鐘打ち、剣、斬撃、パリィ、被弾、祠の鐘、聴き手の足音・叫び・断末魔、暗闇の風）。石の回廊の残響をかける。
- 足音は毎歩聞こえるが、見える波は間隔をあけて出る（聞こえる＝見える、ではない）。
- 会話はリーネだけボイス、ほかは文字。ムービーなし。日本語のみ。
- 操作はキーボード・マウス＋ゲームパッド。
